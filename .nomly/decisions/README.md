# Coordination decisions

Use `.nomly/templates/decision.md` for proposed, temporary, or narrowly scoped cross-agent decisions.

Execution notes remain in tasks. Durable accepted architecture belongs in `docs/adr/`. Architect determines when a decision must be promoted to an ADR, creates or reviews that ADR, and cross-links the records so there is one authoritative rationale.

Suggested names: `DEC-YYYY-NNN-short-slug.md`. States are `proposed`, `accepted`, `rejected`, and `superseded`.
